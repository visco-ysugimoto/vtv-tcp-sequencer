GUIDE

手順

画面ガイド

ハイライト付きの案内です。初回起動時は基本操作ガイドが自動で始まります。途中で閉じる（×）か Esc でいつでも終了できます。

TCP（Network I/O）

このPCから装置の Network I/O へ接続します。装置 IP とポートを入れ、接続テストのあと実行します。

PLCLINK（MC 3E 疑似 PLC）

このアプリが疑似 PLC として待ち受けます。先に「疑似PLC待受開始」を押し、VTV の接続先をこの PC の LAN IP と待受ポートにします。

Field Network（EtherNet/IP）

このアプリが Scanner、VTV が Adapter です。ポートは通常 44818 です。PLCLINK とは同時に使いません。

ファイアウォール

PLCLINK の待受ポートと、Field Network の 44818 を許可します。TCP は装置側がこの PC からの接続を受け付ける必要があります。

BUSY・AK / NK / ER

  • BUSY は装置が処理中の信号です。コマンドは BUSY が落ちるのを待ってから次へ進みます。
  • AK は応答完了。NK は応答なし。ER は異常です。

実行記録

行を開くと、その回の送受信を読めます。
