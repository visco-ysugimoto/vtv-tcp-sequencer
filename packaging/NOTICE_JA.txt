VTV TCP Sequencer ご利用上の注意
================================

■ 起動方法
1. このフォルダごと任意の場所に置いてください（ZIP のままでは起動しないことがあります）
2. VTV_TCP_Sequencer.exe をダブルクリックします
3. Microsoft Edge または Google Chrome が必要です
4. アプリ用ウィンドウを閉じると終了します

■ ウイルス対策ソフトの誤検知について（重要）
本アプリは社内向けの正規ツールです。
Python を Windows 用 exe にまとめる方式（PyInstaller）のため、
ウイルス対策ソフトが「Troj.Win32.*」などの名前で誤って脅威と判定することがあります。
これはよくある誤検知で、マルウェアではありません。

【誤検知された場合の対処】
1. ウイルス対策ソフトの隔離（検疫・駆除）一覧から
   VTV_TCP_Sequencer.exe を「復元」「許可」「例外」する
2. このフォルダ全体を除外（スキャン対象外）に登録する
   例: ...\VTV_TCP_Sequencer\
3. 会社のセキュリティポリシーで除外できない場合は、
   IT 管理者へ「社内配布アプリの誤検知」として除外申請してください
   ・製品名: VTV TCP Sequencer
   ・ファイル: VTV_TCP_Sequencer.exe
   ・ハッシュ: 同梱の SHA256.txt を参照

■ Windows ファイアウォール
PLCLINK（疑似 PLC）を使う場合、待受ポート（既定 5000）の受信を許可してください。
VTV 側の接続先は「この PC の IP:待受ポート」です（検査装置の IP ではありません）。

■ 「127.0.0.1 接続が拒否されました」と出るとき
ブラウザだけ開き、裏側のローカルサーバーが動いていない状態です。
多くの場合、ウイルス対策ソフトが exe を途中で停止／隔離しています。

1. 隔離一覧から VTV_TCP_Sequencer.exe を復元する
2. このフォルダ全体を除外設定に追加する
3. タスクマネージャーで VTV_TCP_Sequencer.exe を終了してから再起動する
4. それでもダメな場合、起動ログを確認する
   %LOCALAPPDATA%\VTV_TCP_Sequencer\startup.log

■ うまく起動しないとき
・Edge / Chrome が入っているか確認する
・ウイルス対策で exe が削除されていないか確認する
・ポート 8765 を使う別アプリが動いていないか確認する
